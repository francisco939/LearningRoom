# 高清场景图生成提示词（Seedream）

当前仓库里的场景是原创 SVG，作为「没有高清图时的回退」。
把 Seedream 生成的 16:9 场景图按下面的文件名放进 `public/scenes/`，刷新页面即可自动切换为高清照片场景，不需要改代码。

## 文件规格

| 项 | 建议 |
| --- | --- |
| 比例 | **16:9 横图**（`2560×1440` 起步，`3840×2160` 更好） |
| 格式 | 先导出 PNG/JPG，再压成 WebP（quality 82–88） |
| 体积 | 单张 ≤ 700 KB（3 张合计 ≤ 2 MB） |
| 文件名 | `rainy-study.webp` / `dusk-library.webp` / `dawn-desk.webp` |
| 位置 | `public/scenes/` |
| 内容 | **不要出现人物、猫、文字、字幕、水印、logo** |

> 画面右侧约 30% 要留出安静的深色墙面：耄耋的相框会叠在那里。
> 画面中下部会叠计时器和控制条，尽量保持桌面干净、不要堆满高对比物体。

## 通用负面提示词

```text
人物，人脸，手，猫，动物，文字，汉字，英文，字幕，水印，logo，签名，卡通，插画，3D渲染，游戏画面，低分辨率，模糊，噪点，过曝，死黑，透视畸变，广角畸变，中央杂乱，过多摆件，鲜艳塑料感，HDR过重，锐化过度
```

## 1. 雨夜书房（rainy-study）

```text
超写实电影摄影，一间没有人的深夜书房，16:9 横构图。
画面左侧 60% 是一扇巨大的深色木框落地窗，窗外是雨夜的城市天际线：密集的暖黄窗灯、霓虹反光、被雨水打湿的玻璃，雨滴在玻璃上拉出细长水痕，窗外景物轻微虚化。
画面中下方是一张深色胡桃木书桌，桌面有真实木纹：摊开的旧书、写满字的稿纸、一只搪瓷杯、一盏黄铜台灯，台灯亮着 2700K 暖光，光晕落在桌面和书页上。
画面右侧 30% 是安静的深色墙面，只有极淡的墙纸纹理和一块很弱的暖光，留白，不要挂画、不要海报、不要文字。
光线：低调照明，暖色台灯与窗外冷蓝环境光形成对比，体积光穿过雨幕，暗部保留细节，不要死黑。
镜头：35mm 定焦，f/2.0，平视略俯，景深自然，前景桌面清晰、窗外柔焦。
质感：Kodak Portra 400 胶片颗粒，真实木材、玻璃、陶瓷、纸张纹理，超精细，8K，HDR，电影感调色，暗调暖棕与冷蓝。
```


## 生成与接入步骤

1. 在 Seedream 选择 **摄影 / 电影感**，比例 **16:9**，清晰度 **2K 或 4K**。
2. 逐条粘贴上面的正向提示词；负面提示词单独填入（若界面支持）。
3. 每张图检查：右侧 30% 是否有干净墙面、中下部是否适合叠字、有没有文字/水印/人物/猫。
4. 导出后压缩为 WebP（Squoosh / `cwebp -q 85`），按文件名放进 `public/scenes/`。
5. `npm run dev`，切换场景；图片加载成功后自动淡入并覆盖 SVG 回退。
6. 如果构图偏移，改 `src/index.css` 里 `.scene-photo` 的 `object-position`，或重新生成。

## 可选：竖屏 / 移动端

当前用同一张 16:9 图 `object-fit: cover` 裁切。若移动端占比高，可再生成 9:16 版本，命名 `rainy-study-mobile.webp`，并在 `SceneDef` 里加 `photoMobile` 字段做媒体查询切换（本次未启用）。
